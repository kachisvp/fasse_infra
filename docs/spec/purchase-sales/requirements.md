# 仕入管理・売上管理 要件定義

## 背景

- フロントエンド: Flutter
- バックエンド: 将来的にSpringBoot(Fargate)で実装予定
- 第一弾はAWS CDKで構築したAPIGateway - Lambda - DynamoDBでWebAPIの受口のみ構築する
- 将来的にFlutter → Fargate(SpringBoot) → Amazon Aurora MySQL Serverlessへ移行する（APIGateway - Lambdaは第一弾限定の暫定構成）

## 目的

飲食店（テーブル会計）を対象に、仕入（仕入先からの仕入伝票）と売上（伝票）を管理する。

## スコープ

- 仕入管理: 仕入先マスタ、品目マスタ、仕入伝票（ヘッダ+明細）のCRUD
- 売上管理: メニューマスタ、売上伝票（ヘッダ+明細）のCRUD

## ユーザーストーリー

- [ ] 仕入担当者として、仕入伝票をヘッダ+明細で登録したい
- [ ] 店舗スタッフとして、売上伝票を登録したい
- [ ] 管理者として、仕入/売上を日付範囲で一覧確認したい

## 受け入れ条件

- [ ] 仕入伝票の登録・一覧（日付範囲）・詳細・更新・削除ができる
- [ ] 売上伝票の登録・一覧（日付範囲）・詳細・更新・削除ができる
- [ ] マスタ（品目・仕入先・メニュー）のCRUDができる
- [ ] 伝票番号（purchase_no / sales_no）は一意である
- [ ] ヘッダと明細は登録時に整合性が保たれる（片方だけ登録される状態にならない）

## スコープ外（第一弾）

- 認証・認可（第一弾は認証なし。将来課題）
- 仕入先/メニュー単位の集計・一覧
- staff_id（担当スタッフ）による売上の紐付け
- 集計・レポーティング機能
- SpringBootへの本実装移行（第一弾はAPIGateway + Lambdaの受口のみ）
