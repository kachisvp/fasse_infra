# 仕入管理・売上管理 要件定義

## 背景

- フロントエンド: Flutter
- バックエンド: 将来的にSpringBootで実装予定
- 第一弾はAWS CDKで構築したAPIGateway - Lambda - DynamoDBでWebAPIの受口のみ構築する
- 将来的にAPIGateway - Lambda - Amazon Aurora MySQL Serverlessへ移行する

## 目的

仕入（仕入先からの仕入伝票）と売上（伝票）を管理する。
memo.md初稿のテーブル定義（table_no, customer_count, menu等）から飲食店向け業務を想定していると推測されるが、要確認。

## スコープ

- 仕入管理: 仕入先マスタ、品目マスタ、仕入伝票（ヘッダ+明細）のCRUD
- 売上管理: メニューマスタ、売上伝票（ヘッダ+明細）のCRUD

## ユーザーストーリー（TODO: 要レビュー・追記）

- [ ] 仕入担当者として、仕入伝票をヘッダ+明細で登録したい
- [ ] 仕入担当者として、仕入先・品目ごとに仕入実績を確認したい
- [ ] 店舗スタッフとして、売上伝票を登録したい
- [ ] 管理者として、仕入/売上を期間で一覧・集計したい

## 受け入れ条件（TODO: 要レビュー・追記）

- [ ] 仕入伝票の登録・一覧・詳細・更新・削除ができる
- [ ] 売上伝票の登録・一覧・詳細・更新・削除ができる
- [ ] マスタ（品目・仕入先・メニュー）のCRUDができる
- [ ] 伝票番号（purchase_no / sales_no）は一意である
- [ ] ヘッダと明細は登録時に整合性が保たれる（片方だけ登録される状態にならない）

## スコープ外（現時点）

- 認証・認可の詳細仕様
- 集計・レポーティング機能の詳細
- SpringBootへの本実装移行（第一弾はAPIGateway + Lambdaの受口のみ）
